# Contributing to Trivia Quiz Game

Thank you for your interest in contributing to the Trivia Quiz Game!

## How to Contribute
1. **Report Bugs**: If you find a bug, please open an issue.
2. **Add Questions**: You can suggest new questions by editing `questions.json`.
3. **Improve UI**: Feel free to submit pull requests for styling or animation improvements.

## Code Style
- Use React hooks for state management.
- Maintain the 8-bit retro aesthetic.
- Ensure all content remains client-side only.

Happy coding!
